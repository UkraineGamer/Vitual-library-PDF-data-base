# Virtual Library PDF Database

Запуск застосунку:

```powershell
python main.py
```

Інтерфейс підлаштовує колонки та навігацію під ширину вікна й масштаб
екрана. У вузькому вікні розділи доступні у списку зверху, а картка книги
розташована під результатами. Довгі сторінки можна прокручувати колесом,
смугою прокручування або клавішами Page Up / Page Down після фокусування
полотна. Якщо масштаб робить вікно вужчим за мінімальну ширину вмісту,
з'являється горизонтальна смуга прокручування.

Регресійні перевірки (потрібен Tk, який входить до стандартного Python для Windows):

```powershell
python -m unittest discover -s tests -v
```

Перевіряються всі розділи на розмірах від 360×640 до 3840×2160,
масштабах 100–200%, прокручування, пошук у фоновому потоці та кеш обкладинок.

Структура проєкту:

```
virtual_library/
├── config.py              # кольори, переклади та UI-типи
├── settings.py            # змінні середовища
├── data/
│   └── catalog.py          # вбудований каталог та історія завантажень
├── services/
│   └── book_search.py     # запити до Open Library і вибір файлу
└── ui/
    ├── app.py             # стан, події та запуск вікна
    ├── components.py      # базові елементи Canvas
    └── views.py           # екрани та панелі інтерфейсу
main.py                    # точка запуску
```
